## Executive summary

Thunder Studio operates in a **zero-competition SEO niche**. Almost all target keywords show difficulty 0. The #1 search term "ห้องซ้อมดนตรีใกล้ฉัน" gets 8,100 searches/month and routes to Google Maps — not organic results. The single highest-ROI action is setting up a Google Business Profile. After that, 6 new pages (3 rooms + pricing + location + about) will capture the remaining commercial-intent traffic. Blog content comes last.

**Current state:** 1 landing page + privacy/terms. SEO score: 55/100. AI visibility: 30/100.
**Target state:** 10+ indexed pages, GBP optimized, FAQ + schema on every page. SEO score: 85+.
**Timeline:** 4 weeks to full implementation.

## Part 2: Google Business Profile (highest priority)

### Why GBP is #1

8,100/mo searches for "ห้องซ้อมดนตรีใกล้ฉัน" go to the Google Maps local pack. Without a GBP listing, Thunder Studio is invisible to 53% of all potential traffic. No amount of website SEO compensates for a missing GBP.

### GBP setup checklist

1. **Claim or create the listing** at business.google.com
   - Business name: Thunder Studio (or Thunder Music Studio)
   - Category: Primary = "Music Rehearsal Space" / Secondary = "Recording Studio"
   - Address: 288, 102-103 Phahonyothin Rd, Anusawari, Bang Khen, Bangkok 10220
   - Phone: 063-546-1924
   - Website: https://thundermusicstudio.com
   - Hours: 10:00-22:00 daily

2. **Verify the listing** (Google sends a postcard or offers phone/email verification)

3. **Optimize the profile**
   - Business description (750 chars): Include "ห้องซ้อมดนตรี" + "สตูดิโอบันทึกเสียง" + "กรุงเทพ" + "บางเขน" naturally
   - Upload 20+ photos: all 3 rooms, equipment close-ups, common area, entrance, parking
   - Add services: "Band Rehearsal", "Solo Practice", "Recording Session", "Mixing & Mastering"
   - Add products/pricing if available
   - Set up messaging
   - Add booking link (Cal.com or website)

4. **Reviews strategy**
   - Ask every customer to leave a Google review after their session
   - Create a QR code at the front desk linking to the review page
   - Respond to every review (Thai + English)
   - Target: 20+ reviews in first 2 months

5. **Google Posts**
   - Weekly post with a photo (room shots, band rehearsals, new equipment)
   - "Book Now" CTA on every post

### GBP impact estimate
- Captures "near me" queries: 8,100 + 390 + 320 = 8,810/mo impressions
- Expected CTR from Maps pack: 15-25%
- Estimated new visits: 1,300-2,200/mo from GBP alone

## Part 4: On-page SEO template

Every new page follows this structure (from seo-site-builder gold-standard template):

### Page structure
1. **H1** — keyword-natural, outcome-focused
2. **Answer block** — 40-60 words, answer-first, quotable by AI (featured snippets + AI Overviews)
3. **H2 sections** — derived from People Also Ask + keyword cluster
4. **FAQ section** — 4-6 Q&As specific to the page, with FAQPage schema
5. **CTA** — "Book a Room" linking to /booking or Cal.com
6. **JSON-LD** — page-type-appropriate schema

### Schema per page type

| Page | Schema type | Key properties |
|------|-------------|----------------|
| Homepage | MusicVenue | (already done) |
| Room pages | Product | name, description, image, offers (PriceSpecification) |
| Pricing | Product + Offer | priceRange, priceCurrency, eligibleDuration |
| Location | LocalBusiness | geo, address, hasMap, openingHours |
| About | AboutPage + Organization | foundingDate, parentOrganization, employee |
| Blog posts | Article | author, datePublished, dateModified |
| All pages | BreadcrumbList | position, name, item |

### Title tag formula
```
[Primary Keyword] — Thunder Studio [Location qualifier]
```
Examples:
- ห้องซ้อมดนตรี ราคา — Thunder Studio กรุงเทพ
- Control Room & Recording Studio — Thunder Studio Bangkok
- ห้องซ้อมดนตรี บางเขน — Thunder Studio อนุสาวรีย์

### Meta description formula
```
[Benefit/answer] + [differentiator] + [CTA]. [Volume keyword naturally included].
```
Max 155 chars. Include the primary keyword in the first 70 chars.
